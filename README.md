# Hi, I'm Tushar

### Civil design engineer moving into AI engineering and evaluation

I'm interested in making engineering work easier to check: clear inputs, explicit units,
traceable calculations and honest treatment of uncertainty. My focus is the intersection of
civil design, Python automation and evaluation of AI-generated technical answers.

**Tools I use:** Civil 3D · AutoCAD · Excel · Python

I'm developing my AI engineering and evaluation skills through practical, reproducible projects.
This portfolio brings civil-engineering questions into small software tools that a reviewer can
run, inspect and challenge.

## How I approach the work

- Make the assumptions visible before interpreting a result.
- Keep calculations reproducible and test the failure cases.
- Separate a useful AI suggestion from verified engineering evidence.
- Document limitations so the next person knows what still needs review.

## Portfolio context
